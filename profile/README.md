# CutLogic 2D — Leftover stock on a sheet you nest

CutLogic 2D keeps one named nest on the desk: the live rectangles, the remnant step in front of you, and a short note the next saw run can read. Extra sheets wait for their own title.

## Session Card

| Focus | Keep only live rectangles on the CutLogic 2D board | A short part list |
| Check | Read the CutLogic 2D remnant before a large change | A confirmed leftover set |

## How CutLogic 2D Sits

CutLogic 2D stays on the sheet you already own. The saw and the remnant rack stay where they are. It is a named shop nest for one cutting job: which rectangles are open, which leftover stock is pinned, and what the next run should read. That local CutLogic 2D nest is enough for everyday sheets on your floor.

## Traffic Light

| Signal | On the CutLogic 2D board | What you do |
|--------|----------------------|-------------|
| Green | Named nest, short part list | Continue the same sheet |
| Amber | Parts from two sheets mixed | Split the set before a large change |
| Red | No title, parts dropped by eye | Stop and name the CutLogic 2D nest first |
| Clear | Handoff written, remnants few | Close CutLogic 2D and leave the nest |

## Open Order

1. Open the last CutLogic 2D nest, not a new empty sheet.
2. Read the remnant list and the last handoff.
3. Finish one visible packing step inside CutLogic 2D.
4. Write what changed, then close with fewer loose rectangles than you found.
5. If the nest feels crowded, drop anything that belongs to a different CutLogic 2D sheet.

## After a Week

Leftover stock after a week of CutLogic 2D nests should still fit the same sheet title. It is the same nest, a shorter part list, and a note that still reads on Monday. Leave CutLogic 2D with a quieter remnant sheet than the one you opened.

## Sign-off

- [ ] The CutLogic 2D nest name is short enough to scan
- [ ] Only live rectangles you own are on the board
- [ ] A second person can read the handoff

## Field Note

CutLogic 2D earns the next nest when remnant stock still matches the sheet you named. Name the nest, keep the live rectangles, finish one visible pack, and write what changed. Extra sheets wait for their own title.
